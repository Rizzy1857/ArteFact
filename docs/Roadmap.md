# ArteFact roadmap

## Completed in 1.0

- Core streaming, chunking, parallel carving, persistent hash caching, dependency health, benchmarks, and expanded tests.
- Native PCAP parsing, sessions, HTTP object extraction, IOC/timeline/statistical analysis, and local threat-feed matching.
- Plugin API 2.0, manifests, dependencies, HTTPS marketplace installation, archive/entrypoint integrity checks, and contributor documentation.
- Markdown, HTML, JSON, and PDF reports; templates; summaries; chain of custody; IOC correlation; timeline SVGs.
- Raw/E01 disk workflows, read-only mounts, filesystem inventory, deleted-file recovery, Registry hive analysis, and Windows shadow-copy discovery. AFF inputs require conversion support from the host toolchain.
- Optional dark Qt interface with case/evidence management, report preview, and timeline workspace.
- Stable packaging, cross-platform CI, performance gates, security tests, security audit, API documentation, and troubleshooting guidance.

## Post-1.0 candidates

- Isolated plugin workers with operating-system sandboxing.
- Native pcapng parsing and full TCP overlap/retransmission handling.
- AFF4-native access without conversion.
- Collaborative case storage, role-based access, and encrypted evidence indexes.
- Richer interactive desktop charts and long-running job supervision.

These are future enhancements and are not claims of the 1.0 API.
